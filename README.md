# Gemini 批量生图队列

一个油猴（Tampermonkey）脚本：把 N 条生图提示词一次性粘进去，它会在 [gemini.google.com/images](https://gemini.google.com/images) 逐条自动提交、等图生成、自动下载，全程不用你点。

> 为「批量出图」而生，不是聊天助手。纯文生图，每条提示词独立成图。

## 它解决什么

在 Gemini 生图页批量出图，最烦的是三件事：一条一条手打、盯着等出图、出完一张张右键另存。这个脚本把这三步串成一条流水线：

- 粘一次，跑 N 条
- 每条**确实出图了**才进下一条，不会把还在生成的回答打断
- 图片自动按序号 + 提示词前缀命名落到下载目录

## 功能

| 能力 | 说明 |
| --- | --- |
| 批量提交 | 支持「空行分隔」（一条提示词可写多段）和「每行一条」两种切分 |
| 独立会话 | 默认每条新开一个会话，避免前一张图的风格污染后一张 |
| 出图判定 | 以「图片元素出现 + 生成已停止」为成功信号，不是死等固定时间 |
| 自动下载 | 多图全部下载，命名 `003_提示词前20字_1.png` |
| 断点续跑 | 队列与进度存在 localStorage，刷新、关标签页后能接着跑 |
| 失败不卡队 | 单条失败记录原因后跳到下一条；配额/限流则整队暂停 |
| 自检 | 页面结构变动时可一键打印选择器状态，便于反馈修复 |

## 安装

### 方式一：直链安装（推荐）

1. 浏览器装好 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 点开脚本直链，Tampermonkey 会自动弹出安装页：

```
https://raw.githubusercontent.com/ercichen12/gemini-image-batch/main/gemini-image-batch.user.js
```

3. 点「安装」

### 方式二：手动

Tampermonkey 面板 → 添加新脚本 → 全选删掉模板 → 粘贴本仓库 `gemini-image-batch.user.js` 全文 → Ctrl+S 保存。

## 使用

1. 打开 <https://gemini.google.com/images>，确认已登录、页面能正常出图
2. 右下角出现「Gemini 批量生图」面板（可拖动，`—` 收起，`×` 隐藏，刷新恢复）
3. 把提示词粘进文本框，看下方「共 N 条」是否符合预期
4. 点「开始」，脚本自动跳转/提交/等待/下载
5. 中途可「暂停」（当前这条不会重发）、「跳过当前」、「清空」

### 分隔规则

默认**空行分隔**：连续两个换行算作下一条，所以单条提示词里可以写多段描述。

```
一只橘猫坐在窗台，晨光斜射，胶片质感，浅景深
```

切成「每行一条」后，每个换行就是一条，适合一行一条的短提示词清单。

### 文件命名

```
001_一只橘猫坐在窗台晨光斜射_1.png
001_一只橘猫坐在窗台晨光斜射_2.png
002_赛博朋克城市夜景霓虹广角.png
```

序号对齐队列顺序，前缀取提示词前 20 字（非法字符已替换），一条出多张时追加 `_1` `_2`。

## 设置项

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 每条额外缓冲 | 3 秒 | 上一条下载完到下一条提交之间的等待 |
| 单条超时 | 180 秒 | 超过则记为失败并跳到下一条 |
| 每条新开会话 | 开 | 保证每条提示词互不干扰；关掉则在同一会话里连续发 |
| 自动下载 | 开 | 关掉则只在页面上生成，不落盘 |

## 工作原理

每条提示词走一遍固定流水线：

```
确认在 /images 页 → 等输入框就绪 → 校验 Images 标签 → 注入文本
→ 点发送 → 轮询出图 → 全部下载 → 缓冲 → 下一条
```

- **注入文本**：Gemini 输入框是 Quill 富文本，直接改 `textContent` 无效，必须走 `execCommand('insertText')` 并让框架收到 input 事件
- **出图判定**：生成中途的「停止」按钮消失 + 响应区出现 ≥256px 的图片，连续两次轮询稳定才算完成。只看按钮会漏（图是异步渲染的），只看图会误判（模板缩略图也是图）
- **下载**：优先 fetch 取 blob 自行命名；跨域受限时退到 Tampermonkey 的 `GM_download`；再不行就新标签打开原图让你手动存
- **防重复**：发送前记录时间戳，若中途刷新，重入时只等结果不会重发

## 常见问题

**Q：图片没下载下来，Chrome 弹「此网站尝试下载多个文件」**
A：点地址栏右侧的拦截图标，选「允许」。浏览器对连续自动下载有硬限制，第一次必须手动放行。

**Q：脚本找不到输入框 / 点了没反应**
A：展开面板底部「设置与自检」→ 点「自检当前页面」，把日志区内容贴到 issue。Gemini 前端改版会导致选择器失效，自检日志能直接定位是哪一层断了。

**Q：某条只回了文字，没出图**
A：通常是提示词触发了安全策略或模型判断不需要画图。这条会记为失败并自动跳到下一条，不会卡住队列。

**Q：跑一半停了，提示「配额或限流」**
A：Gemini 生图有额度上限。脚本会暂停整队，等额度恢复后点「继续」即可，已完成的不会重跑。

**Q：关掉标签页再打开还在跑吗**
A：进度会保留，但脚本本身停了。重新打开页面后点「继续」即可从断点接着跑。

## 已知限制

- 依赖 Gemini 网页结构，官方改版后可能需要更新选择器
- 只做纯文生图，不支持上传参考图做图生图
- 不干预 `Aspect ratio` 和模型选择，请在页面上设好一次，循环沿用
- 串行执行，一次只跑一条，不做并发
